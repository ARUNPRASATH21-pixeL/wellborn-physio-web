# Wellborn Physio

A modern and professional physiotherapy clinic website designed to provide patients with an easy way to explore physiotherapy services, learn about treatments, and connect with the clinic.

 🌐 About

Wellborn Physio is a healthcare-focused web platform built with a clean, modern, and responsive user interface.

The website is designed to provide:

- Physiotherapy service information
- Treatment details
- Clinic information
- Patient-friendly navigation
- Appointment/contact options
- Responsive experience across desktop, tablet, and mobile devices
  
✨ Features
- Modern premium UI
- Fully responsive design
- Smooth navigation
- Service sections
- Treatment information
- Contact section
- Mobile-friendly layout
- Fast and optimized frontend
- Clean component-based architecture

🛠️ Tech Stack
- React.js
- JavaScript
- HTML5
- CSS3
- React Router
- Lucide Icons
- Vite
